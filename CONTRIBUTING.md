# Contributing

AgentRoster is at an early design stage (v0.1 drafts). Issues and discussion are welcome,
especially on the spec, the agent types and the assessment checks.

- **Spec changes:** open an issue first. The core changes only with a new standard version;
  new ideas can start as a namespaced extension.
- **New check packs:** the anatomy and findings format will be documented with the skill.
- **Adapters:** read-only, never invent values, never copy secrets.
- **Design changes:** open an issue; the maintainer records decisions.
